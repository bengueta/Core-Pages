# הפעלת GitHub Pages (חובה פעם אחת)

ה-build כבר על ענף **`gh-pages`**. בלי שלב זה באתר יהיה **404**.

1. פתח: https://github.com/bengueta/Core-Pages/settings/pages  
2. **Build and deployment → Source:** בחר **`Deploy from a branch`**  
3. **Branch:** `gh-pages` · **Folder:** `/ (root)`  
4. לחץ **Save**  
5. המתן 1–3 דקות  

אתר: https://bengueta.github.io/Core-Pages/

אם עדיין ריק — Actions → הרץ מחדש **Deploy to GitHub Pages** (workflow_dispatch).
