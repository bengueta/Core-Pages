## מה זה

את זה מאחסנים ב־GitHub כמשאבי **קבצים סטטיים** — בלי Convex, בלי Cookies של האתר הראשי, וללא Doppler מהמוצר המוגן.

## שתי דרכים לפרסם

- **פוסט בפורום** — מתחברים עם GitHub ופותחים נושא ב[פורום](../forum/)
  (GitHub Discussions). מופיע מיד, בלי PR. זו הדרך לקהל הקצה.
- **מאמר רשמי** — דרך **Pull Request**:
  1. העתיקו את התבנית מ־`CONTRIBUTING.md`.
  2. פתחו **Pull Request**.
  3. אחרי merge, האתר מתעדכן דרך GitHub Actions.

דיונים, תגובות והגדרת הפורום: ראו **`DISCUSSIONS_AND_GISCUS.md`**.
